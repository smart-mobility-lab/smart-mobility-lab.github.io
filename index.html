Overview

The Smart Mobility Benchmark evaluates whether AI systems can answer transportation analytics questions using structured CSV data and schema metadata. The benchmark focuses on two capabilities: planning the correct analysis and producing a final answer grounded in the provided data.

Data Tables

The benchmark uses a fixed one-month data snapshot. The schema files describe the available tables and columns so that systems can reason from metadata rather than relying on hard-coded assumptions.

Question Set

The benchmark includes both single-table and multi-table analytical questions. Public question IDs do not reveal internal difficulty categories. Systems must infer the relevant tables, fields, aggregation level, and analysis logic from the question and schema metadata.

Single-table tasks

  • Filter by time window, movement, class, direction, or intersection.
  • Group and aggregate counts, violations, delay, or speed bins.
  • Rank intersections, movements, classes, or event types.

Multi-table tasks

  • Join or compare tables using normalized intersection labels.
  • Compute ratios, rates, and exposure-normalized measures.
  • Build normalized scores and combined safety or activity rankings.

Submission Workflow

Participants may submit Track 1, Track 2, or both. Track 1 and Track 2 outputs should be uploaded as separate CSV/JSON files so that each file can be evaluated by the correct scoring script.

Repository-based submissions are used only to retrieve the specified CSV/JSON output. Participant code will not be executed.

Required Track 1 output fields

ID, answerable, selected_tables, key_fields, granularity, query_logic, sql_or_plan, assumptions

Required Track 2 output fields

ID, final_response or pred_final_answer, and any required execution/output columns defined in the released submission template.
